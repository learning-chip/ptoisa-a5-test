# TileLang-extracted A5 PTO kernels (no TileLang at runtime)

Standalone project mirroring [`pto-kernels/examples/a5_sim/kernels`](../../pto-kernels/examples/a5_sim/kernels): **bisheng-built `.so` libraries**, **ctypes launch via `extern "C" void call(...)`**, and **torch_npu** drivers — without importing TileLang at runtime.

Sources were extracted from the **13 PASS** tilelang-ascend examples recorded in [`../tilelang_sim/`](../tilelang_sim/) (shapes from `configs/pass_shapes.json`).

## Layout

```
tilelang_extracted_sim/
├── kernels/                  # 19 PTO C++ files from JITKernel.get_kernel_source()
├── build/                    # lib*.so (generated)
├── common/
│   ├── extract_sources.py    # compile-only dump via runpy + JITKernel hook
│   ├── build.py              # bisheng (dav-c310, -DREGISTER_BASE, TileLang templates)
│   └── torch_runtime.py
├── manifest.json             # kernel ids, shapes, call metadata
├── extract_all.sh
├── run_kernel.py             # torch ctypes smoke tests
└── run_msprof.sh             # Ascend950PR_9599 simulator wrapper
```

## Prerequisites

```bash
source /usr/local/Ascend/ascend-toolkit/latest/bin/setenv.bash
# TileLang pre-installed at /sources/tilelang-ascend (for re-extraction only)
pip install torch torch-npu
```

## Re-extract PTO sources

```bash
cd /workdir/ptoisa-a5-test/tilelang_extracted_sim
./extract_all.sh
```

Uses `../tilelang_sim/common/bootstrap.py` (forces `target=pto`, `platform=A5`), hooks `JITKernel.__init__`, runs each PASS example under `runpy` with execution patched out, and writes `kernels/*_a5.cpp`.

## Build

```bash
python3 -m common.build --kernel elementwise_elementwise_add_m128_n256
python3 -m common.build --all
```

Build flags match TileLang `libgen.py` for PTO/A5: `--cce-aicore-arch=dav-c310`, `-DREGISTER_BASE`, includes from `TL_ROOT/src` (for `tl_templates/pto/common.h`) and `3rdparty/pto-isa`.

## Run (torch + ctypes, no TileLang)

```bash
python3 run_kernel.py --list
python3 run_kernel.py --kernel elementwise_elementwise_add_m128_n256

# All 19 kernels (under msprof simulator recommended)
./run_msprof.sh --all
./run_msprof.sh --kernel gemm_example_gemm_m128_n256_k128
```

Each kernel exposes `call(uint8_t* handles..., void* stream)` as generated by TileLang PTO codegen. `run_kernel.py` allocates tensors + workspace buffers to match `manifest.json` `params` / `out_idx`.
